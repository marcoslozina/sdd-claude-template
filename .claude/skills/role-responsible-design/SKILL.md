# Skill: Responsible Design

## Base principle

Design is an act with consequences. Every decision — what to show, what to hide, what to make easy, what to make hard — affects user behavior. Responsible design means making those decisions aware of their impact.

Core references: [Anthropic Model Spec — Avoiding Manipulation](https://www.anthropic.com/research/model-spec) and [Nielsen Norman Group — Dark Patterns](https://www.nngroup.com/articles/dark-patterns/).

---

## Dark patterns — never

Dark patterns exploit cognitive biases to make the user do something they would not do if they fully understood. They are both a design and an ethical failure.

| Dark pattern | Description | Concrete example |
|---|---|---|
| **Confirmshaming** | Shaming the user for declining | "No, I'd rather pay more" as the decline option |
| **Roach motel** | Easy to get in, hard to get out | Subscribe in 1 click, cancel in 7 steps |
| **Misdirection** | Steering attention away from the real option | A "Continue" button leads to an unrequested subscription |
| **Hidden costs** | Costs that show up late in the flow | Final price ≠ price shown at the start |
| **Trick questions** | Confusing checkboxes or double negatives | "I don't want to not receive emails from partners" |
| **False urgency** | Timers or stock counts that aren't real | "Only 2 left! Offer ends in 10:00" (always) |
| **Bait and switch** | Promise X, deliver Y | A download button installs something else |
| **Privacy zuckering** | Permissive privacy defaults | "Share with everyone" pre-selected |
| **Disguised ads** | Advertising that looks like content | A "recommended result" that is paid |

## Designing AI interfaces — principles

When the product exposes AI to the user (chatbots, suggestions, content generation):

### Mandatory transparency
```
✅ The user knows when they are talking to AI vs a human
✅ The user knows when content was generated by AI
✅ The confidence/certainty level is communicated clearly
✅ The system's limitations are visible and honest
```

```
❌ Passing AI off as human without disclosure
❌ Hiding that a response was generated automatically
❌ Presenting AI output as fact without indicating uncertainty
❌ Creating the illusion of deep emotional understanding
```

### No manipulation
The system must not:
- Create artificial urgency so the user makes rushed decisions
- Use personalization to exploit emotional vulnerabilities
- Design to maximize engagement at the cost of user wellbeing
- Make it hard to end a session or turn off a feature

### User autonomy
```
✅ The user can reject AI suggestions without penalty
✅ The user can turn off personalization
✅ The user can view and delete their history
✅ The user can exit the flow at any point
✅ The user controls when and how the AI acts on their behalf
```

## Privacy in UX (Privacy by Design)

Privacy is designed in from the start, not bolted on at the end.

### Real consent
```
❌ Pre-checked "I agree to receive communications from partners"
❌ "Accept cookies" vs "Configure" with different colors
❌ Scrolling and reading 30 pages in order to decline

✅ Options with equal visual prominence
✅ Declining is as easy as accepting
✅ Consent is specific, informed, and revocable
```

### Data minimization in forms
```
❌ Asking for a full date of birth when you only need to know whether they are of legal age
❌ Making phone number a required field for something that works without it
❌ Full address for shipments that only need the city

✅ Only ask for what you use
✅ Explain why each sensitive field is requested
✅ Optional fields clearly marked
```

### Data transparency
- The user can see what data the system holds about them
- The user can request deletion
- Policy changes are communicated with enough advance notice

## Inclusivity — beyond technical accessibility

### Inclusive language in UI copy
```
❌ "Hey guys" / "Sir/Madam" / forced binary
✅ "Hello" / "Dear customer" / non-binary options where applicable

❌ Technical or corporate jargon that excludes
✅ The user's vocabulary, not the system's

❌ Examples using only Anglo names and US cities
✅ Examples that reflect cultural diversity
```

### Identity forms
```
✅ Preferred name separate from legal name (where applicable)
✅ Optional pronouns
✅ Gender as a free-text field or with a "Prefer not to say" option
✅ Date of birth not required when it isn't necessary
```

## Digital wellbeing — designing against addiction

Not all engagement is valuable. Responsible design does not maximize screen time at any cost.

### Signs of addictive design to avoid
```
❌ Infinite scroll with no natural stopping point
❌ Autoplay without consent
❌ Notifications designed to create anxiety if not checked
❌ Variable reward schedules (casino mechanics) in non-gaming contexts
❌ Streaks that create fear of loss rather than positive motivation
```

### Alternatives
```
✅ Show "You've seen all the new content" instead of infinite scroll
✅ Suggested breaks after X time of use
✅ Batched notifications instead of constant ones
✅ Honest progress, not inflated
```

## Responsible design checklist

Before shipping any screen:

```
□ Does the user understand what is going to happen before clicking?
□ Is declining as easy as accepting?
□ Does the error state explain what went wrong and how to fix it?
□ Do the defaults favor the user or the business?
□ If the user were a family member of mine, would I be comfortable showing them this?
□ Is the AI in this flow clearly identified as AI?
□ Can the user undo or exit at any point?
□ Are only the data actually used being requested?
□ Does the language exclude any group because of how it's written?
```
